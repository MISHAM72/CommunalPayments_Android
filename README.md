# 🧾 Communal Payments (Коммунальные платежи)

[![Kotlin](https://img.shields.io/badge/Kotlin-2.0-blue)](https://kotlinlang.org)
[![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-2025.04-green)](https://developer.android.com/jetpack/compose)
[![Version](https://img.shields.io/badge/version-2.5.5-brightgreen)](https://github.com/MISHAM72/CommunalPayments_Android/releases)

Приложение для учёта и расчёта коммунальных платежей.  
Позволяет вести историю оплат, настраивать названия услуг и номера лицевых счетов, а также **делиться историей** через системные средства.

---

## 🚀 Функционал

- **Расчёт платежей** для 12 услуг:
    - ⚡ Электричество, 🔥 Газ, 💧 Вода (по счётчикам)
    - 🗑️ Мусор, 🌡️ ЗОНТ (отопление), 📶 Интернет
    - 📱 МТС, 🟦 Тинькофф, 💰 Налоги
    - 🚇 Тройка, 🚗 ОСАГО, **🏢 Общежитие**
- **📊 Годовая аналитика расходов** (кнопка «📋 Всего»):
    - Столбчатая диаграмма с расходами за текущий год по всем 12 услугам
    - Общая сумма расходов за год
    - При нажатии на столбец появляется подсказка с полным названием услуги и точной суммой (отпускание скрывает подсказку)
    - Данные берутся из истории оплат со статусом 🔴 (оплачено)
    - Анализ работает для счётчиков и периодических услуг независимо от языка интерфейса
- **💰 Учёт доходов** (новое в v2.5.5):
    - Добавление доходов с выбором категории (зарплата, подработка, инвестиции и др.)
    - Просмотр и редактирование списка доходов по категориям
    - Удаление отдельных записей или всех доходов по категории
    - Годовая аналитика доходов с графиком и итоговой суммой
- **📦 Резервное копирование** (новое в v2.5.5):
    - Экспорт всех данных (истории, настроек) в ZIP-архив
    - Импорт резервной копии для восстановления на новом устройстве
- **Сохранение истории** расчётов с датами и статусами оплаты
- **Редактирование названия услуги** и номера лицевого счёта
- **Просмотр истории** с возможностью изменять статус платежа
- **Редактирование всей истории** вручную (текстовый режим)
- **📄 Экспорт истории в PDF**:
    - Создание PDF-файла с детализацией платежей по выбранной услуге или за весь период
    - Автоматическое сохранение PDF в локальное хранилище приложения
    - Отправка PDF через стандартное системное меню (Share) – можно поделиться через мессенджеры, email, облако
- **Автоматическое сохранение** введённых данных между сеансами
- **Тёмная/светлая тема** (следует за системной)
- **Поддержка языков**: Русский, English
- **🔊 Звуковое сопровождение** интерфейса:
    - Уникальные звуки для каждой услуги при выборе
    - Звуковой отклик на все основные действия (расчёт, сохранение, навигация, копирование, выбор банка)
- **📋 Копирование суммы**:
    - Кнопка копирования итоговой суммы в буфер обмена во всех экранах
    - Подтверждение копирования через Toast и звуковой сигнал
- **🏦 Выбор банка для оплаты**:
    - Список популярных банков (СберБанк, Т-Банк, ВТБ, Альфа-Банк, Точка, ЮMoney, БКС)
    - Автоматическое определение установленных банковских приложений
    - Мгновенный переход в выбранный банк для завершения платежа
    - Звуковое подтверждение при открытии диалога выбора банка
    - ✅ Полная поддержка Android 8.0 (API 26) и выше – адаптивная иконка, корректная вёрстка с системными отступами, работа на всех экранах

## 🛠 Технологии

- **Kotlin** + **Coroutines** (StateFlow)
- **Jetpack Compose** (Material 3)
- **Чистая архитектура** (слои app, data, domain, presentation)
- **MVVM** (ViewModel, StateFlow)
- **SharedPreferences** (хранение пользовательских настроек)
- **FileManager** (работа с историей платежей)
- **Парсинг текстовых файлов** для извлечения сумм и дат из истории (HistoryParser)
- **Агрегация данных** (годовые итоги, помесячная разбивка) – `AnalyticsRepositoryImpl`
- **PDF generation** (Android PdfDocument)
- **MediaPlayer** (звуковое сопровождение)
- **Gradle Kotlin DSL**
- **Адаптивные иконки** (Android 8+) через Image Asset Studio

---

## 🧱 Архитектура

Проект разделён на 4 слоя:

- `app` — точка входа (`MainActivity`), сборка зависимостей, навигация
- `domain` — бизнес-логика и модели (не зависит от Android)
- `data` — репозитории, работа с файлами, SharedPreferences, `HistoryParser`, `AnalyticsRepositoryImpl`
- `presentation` — экраны (Compose), ViewModel, фабрики, мапперы, утилиты, `AllServicesSummaryScreen`, `AllServicesSummaryViewModel`

Все репозитории реализуют интерфейсы из `domain`, что обеспечивает тестируемость и гибкость.

## 🔊 Звуковое сопровождение

В приложение добавлена система звуковой обратной связи:

| Действие               | Звук                                   |
|:-----------------------|:---------------------------------------|
| Выбор услуги           | Уникальный звук для каждой из 12 услуг |
| Кнопка «Рассчитать»    | Звук монетки / расчёта                 |
| Кнопка «История»       | Звук открытия двери                    |
| Кнопка «Назад»         | Звук возврата                          |
| Кнопка «Редактировать» | Звук клика                             |
| Кнопка «Поделиться»    | Звук кукушки                           |
| Сохранить / Отмена     | Звуки подтверждения / отмены           |
| Копировать сумму       | Звук копирования                       |
| Выбрать банк           | Звук открытия диалога                  |

Все звуки находятся в `res/raw/`, логика — в `presentation/utils/SoundUtils.kt`.
